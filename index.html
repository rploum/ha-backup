Home Assistant Ploum

Home Assistant Ploum is a private, single-user setup of the open-source home automation software Home Assistant, run by Rob Ploum in his own home.

This Google OAuth app exists for one purpose: it lets that Home Assistant installation upload its own backup files to, and read them back from, a folder in Rob Ploum's personal Google Drive. It is not offered to anyone else.
